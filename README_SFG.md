# SFG + NNSCA [2,1] BBM search

Minimal single-function-generator (SFG) pipeline for searching exact solutions of
the Benjamin-Bona-Mahony (BBM) equation with the fixed one-hidden-node NNSCA
structure `[2,1]`.

The trial solution is

```text
u(x, t) = c0 + c1 * f(a*x + b*t + d)
```

where `f` is generated by the SFG and `a,b,d,c0,c1` are symbolic NNSCA
parameters. SFG-internal parameters such as `alpha` in `sech(alpha*z)**2` stay
separate from the network parameters.

## Run

```bash
python3 scripts/test_sfg_bbm_21.py
```

Pure generated-only search:

```bash
python3 scripts/test_sfg_bbm_21.py --mode generated-only --seed 101 --num-candidates 100
```

Deep [2,3,2,1] network (hierarchical trial with the same generated activation):

```bash
python3 scripts/test_sfg_bbm_21.py --widths 2,3,2,1 --mode generated-only --num-candidates 3 --seed 101
```

Stage-by-stage diagnosis for a completed run:

```bash
python3 scripts/pdes/diagnose_sfg_solver.py results/sfg_bbm/processed_candidates.json
```

Phase-4 [2,2,1] experiment and reports:

```bash
python3 scripts/pdes/run_sfg_phase4.py
```

Mixed seed + generated search (also the default):

```bash
python3 scripts/test_sfg_bbm_21.py --mode mixed
```

Five independent generated-only seeds:

```bash
python3 scripts/pdes/run_sfg_phase3_multi_seed.py --num-candidates 100
```

Fast check with only the four required test functions:

```bash
python3 scripts/test_sfg_bbm_21.py --quick
```

The legacy hierarchical BBM engine still lives in
`scripts/pdes/bbm_pipeline.py`. The modified `scripts/pdes/bbm_nnsca.py` now
runs this minimal `[2,1]` workflow.

## Test

```bash
python3 -m pytest tests/test_sfg_bbm_21.py -q
```

## Output

Results are written to `results/sfg_bbm/`:

- `generated_functions.json`
- `candidate_summary.csv`
- `exact_solutions.json`
- `failed_candidates.json`
- `processed_candidates.json`
- `audit_report.md`
- `search_log.txt`
- `maple_manual_tasks/`

A solution is reported as exact only after its raw BBM residual is certified
zero by independent back-substitution. Maple is never invoked; the manual task
directory is only a human-readable fallback for expressions SymPy cannot
resolve.

## Extend

Add primitives in `_atom_pool()` in
`scripts/pdes/sfg_bbm_21.py`. Jacobi functions use the custom `Function`
subclasses in `src/sigs/jacobi.py`, which provide exact first-argument
derivatives and safe SymPy parsing through `SYMPY_LOCALS`.
