# SFG-NNSCA Refactor Reports

Phase 0 documents are collected here for easier management.

- `SCRIPTS_CLEANUP_REPORT.md`: deleted and retained scripts, reasons, dependency checks, new scripts layout.
- `ARCHITECTURE_AUDIT.md`: current data flow, retained Stage2 modules, modules to replace, old/new interface.
- `DIRECTORY_PLAN.md`: target source layout and transition rules.

Later phases will add implementation notes and test reports in this directory unless a separate `results/` experiment report is required by the task.

Implemented phase notes are now present in this directory: `PHASE1_NETWORK_MODEL.md` through `PHASE6_CROSS_EQUATION.md` and `TEST_REPORT.md`.
