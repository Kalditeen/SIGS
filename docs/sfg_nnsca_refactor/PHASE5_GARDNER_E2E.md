# Phase 5: Gardner End-to-End Run

## Entry point

`scripts/run_gardner.py` uses the new search/compile/Stage2 pipeline.

## Small verification run

Command:

```bash
python3 scripts/run_gardner.py \
  --num-structures 14 \
  --max-hidden-layers 1 \
  --max-width-per-layer 1 \
  --max-total-hidden-nodes 4 \
  --results-dir results/refactor/gardner
```

Observed summary:

- generated structures: 14
- unique structures: 14
- compile success: 14
- constraint extraction success: 14
- solve success: 14
- exact candidates: 3
- exact branches: 4

These exact branches are generated by the new structure search, compiled by
the new compiler, and certified by the existing raw-residual Stage2 gate.  No
known Gardner parameter relations are hardcoded in search, compiler, or solver.

Outputs are stored in `results/refactor/gardner/`.
